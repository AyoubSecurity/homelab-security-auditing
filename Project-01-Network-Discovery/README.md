# Homelab Security Auditing

Practical network and cybersecurity auditing projects performed in an isolated
virtualized laboratory environment.

### Project 01 — Network Discovery & Asset Inventory

Initial network discovery and asset inventory assessment using Kali-Linux, Windows 7 and Ubuntu Server as VMs and nmap to discover and scan.

**Topics:**
- Network discovery
- Host identification
- Service enumeration
- OS detection
- Asset inventory
- Evidence collection
- Security reporting
